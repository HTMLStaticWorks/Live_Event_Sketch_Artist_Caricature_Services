# SketchRush

**Live Event Sketch Artist & Caricature Services Website**

## Overview
SketchRush is a premium, retro-editorial HTML template built for live event sketch artists and caricaturists. It features a bold, artisan design, dark/light mode, RTL support, and a responsive layout without reliance on heavy frameworks like Tailwind or React.

## Features
- **Pure HTML/CSS/JS**: Vanilla development for maximum speed and simplicity.
- **Design System**: Strict adherence to a 3-color palette (Ink Black, Warm Cream, Vivid Saffron).
- **Responsive**: Full desktop, tablet, and mobile views. Hamburger drawer under 1024px.
- **Theme Toggle**: Dark and light mode persists via `localStorage`.
- **RTL Support**: Native logical CSS properties + RTL toggle logic.
- **Form Validation**: Client-side validation built into booking and auth forms.

## Setup
Simply open `index.html` in your browser. No build steps required.

## Customization
Update the CSS variables in `:root` inside `style.css` to modify the global theme colors, typography, or spacing.
